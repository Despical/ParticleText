# Security Policy

Report vulnerabilities privately to `contact@despical.dev`. Do not open a public
issue containing an exploit or private server information.

Include the affected version, server and Java versions, reproduction steps,
expected impact, and relevant sanitized logs. Do not include credentials, private
player data, destructive payloads, or anything that could damage a live server.

## Scope

- Command permissions, inventory actions, and chat interactions.
- Renderer records, atomic writes, and configuration reloads.
- Placeholder output and optional integrations.

Only the latest public Particle Text version is supported. Confirmed reports are
reviewed privately and fixed before coordinated public disclosure.
